# Simulations

Robot simulations for TrickFire Robotics - Gazebo Harmonic (ROS 2 Jazzy) for robot subsystems, and Project Chrono (SCM) for terrain/wheel physics.

## Documentation

**Full documentation is at [docs.trickfirerobotics.com/simulations](https://docs.trickfirerobotics.com/simulations)**

- [Getting Started](https://docs.trickfirerobotics.com/simulations/setup/getting-started/) - native setup, Dev Container alternative, first launch
- [Running Gazebo](https://docs.trickfirerobotics.com/simulations/guides/gazebo/) - `sim gazebo` CLI usage and flags
- [Running Chrono](https://docs.trickfirerobotics.com/simulations/guides/chrono/) - `sim chrono` CLI usage
- [Moving Joints](https://docs.trickfirerobotics.com/simulations/guides/moving-joints/) - Joint GUI and `move_joints` CLI node
- [Adding a New Robot](https://docs.trickfirerobotics.com/simulations/guides/adding-robots/) - OnShape to Gazebo with `sim gazebo create`
- [Reference](https://docs.trickfirerobotics.com/simulations/reference/docker-environment/) - Docker environment, launch system, robot packages in depth
