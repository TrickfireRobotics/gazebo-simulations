---
title: Running Chrono
description: How to run Project Chrono SCM terrain simulations.
---

Chrono SCM (Soil Contact Model) terrain simulations run inside the Dev Container, where Project Chrono is pre-built into the image.

## Dev Container

```bash title="Inside devcontainer"
sim chrono run
```

This builds the C++ simulation from `chrono/` (if not already built) and runs it. A Vulkan window opens in the VNC desktop showing the terrain simulation.

<Callout type="info" title="Cleaning">

    To force a clean rebuild (could help during any unexpected error) run:

    ```bash title="Inside devcontainer"
    sim chrono clean
    ```

    This deletes `chrono/build/`.

</Callout>

## Troubleshooting

<Accordions>
    <Accordion title="Chrono window doesn't appear">
        Chrono uses [Vulkan](https://en.wikipedia.org/wiki/Vulkan) for rendering. Make sure you followed all the steps for your platform [during setup](../setup/docker)
    </Accordion>

</Accordions>
