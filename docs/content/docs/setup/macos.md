:::info[Deprecated]
This guide documents a native MacOS setup that is no longer actively maintained. The recommended approach is to use the [Dev Container](../devcontainer/) workflow, which works on all platforms including Mac.
:::

For macOS users, the Dev Container provides a consistent, pre-configured environment without the complexity of native setup. This is the primary recommended workflow.
