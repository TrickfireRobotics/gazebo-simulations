# Setting Up an RViz Config

By default, robots generated by `genbot` do not include an RViz config file because RViz configurations are difficult to generate programmatically. However, creating one manually is straightforward.

## Why you need an RViz config

An RViz config (`.rviz` file) stores your visualization setup — which displays are active (robot model, TF frames, etc.), camera position, and window layout. Without one, RViz opens with a blank canvas every time. Once saved, the launch file loads it automatically so your visualization is ready on startup.

## Steps

1. **Launch the simulation** without an RViz config (it will open with default/blank settings):

   ```bash
   ./scripts/launch_sim.sh <your_robot>
   ```

2. **Set the Fixed Frame** — In the left panel under **Global Options**, set **Fixed Frame** to `base_link`. `genbot` always generates a `base_link` even if it is not in the OnShape model.

3. **Add the Robot Model display** — Click **Add** in the bottom-left, select **RobotModel**, then expand it and set **Description Topic** to `/robot_description`.

4. **Save the config** — Go to **File > Save Config As** and save it to:

   ```
   robot-sim/<your_robot>_bringup/config/<your_robot>.rviz
   ```

5. **Uncomment the RViz lines in the launch file** — Open `<your_robot>_bringup/launch/sim.launch.py` and uncomment the lines marked `# UNCOMMENT WHEN RVIZ CONFIG SETUP` so the launch file loads your config:

   ```python
   rviz_config = get_asset("<your_robot>_bringup", "config", "<your_robot>.rviz")
   ```

   and the `arguments` block inside the `rviz` Node.

After this, subsequent launches will automatically load your RViz config.
